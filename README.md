# BSMS Desktop

Downloads for the BSMS (Bike Showroom Management System) desktop app.

## Download

Get the latest installer from the [Releases page](../../releases/latest).

- **Mac (Apple Silicon)** — `BSMS-*-mac-arm64.dmg`
- **Mac (Intel)** — `BSMS-*-mac-x64.dmg`
- **Windows** — `BSMS-*-windows-setup.exe`

## Installing

These installers are currently **unsigned**, so your OS will show a security warning the first time you open them. This is expected, not a sign of tampering:

- **Mac**: right-click the app → **Open**, then confirm in the dialog. (Or: System Settings → Privacy & Security → **Open Anyway**.)
- **Windows**: click **More info** → **Run anyway** on the SmartScreen prompt.

## First run

The app includes a short setup wizard for your showroom details and creates your Owner login. It runs as a 7-day free trial; after that you'll need an activation key to continue — contact us if you don't have one.
